# Tutorial boundary, character clearance and Halloween interface / v0.15

Date: October 16, 2026 (America/Chicago). Source: direct user feedback and the supplied desk/ending photographs. No new participant study is claimed.

## Reported problems and final changes

1. **Characters intersect furniture or overlap at departure.** Button previously shared the foyer desk's position. Button and Pip now stand behind their desks with room for turning and waving sleeves. The ending stages its queue beyond dispatch, sends the helpers through the narrow doorway at separate times, and spreads them outside. A fixed exterior cinematic camera replaces the camera sweep through the desk. The whole group stays on the unobscured right side of the ending card. The lantern is carried ahead of Pip's body, rather than inside it.
2. **Tutorial and formal play are indistinguishable.** The title now explicitly says Start the tutorial. The foyer teaches only looking, walking, picking up and placing the crate. Crossing its door opens a paused TUTORIAL COMPLETE card, explains the lantern objective and the three main work areas, and requires Start making the lantern / Enter. The right panel changes permanently from TUTORIAL to NIGHT SHIFT. Returning to the foyer does not restart the tutorial or replace the formal objective. The Archive remains part of the main game and introduces the chime through harmless contextual practice; Assembly applies that mechanic under its explained safety challenge. This is an explicit phase boundary in one continuous factory scene, not a claim of separate Unity scenes.
3. **10 / 31 resembles task completion.** Removed the date from the task panel. A phase name and chapter title now sit above a separate Tasks completed: n / total line and View tasks button. The title spells out Halloween Night. Production progress sits below the enlarged task card.
4. **Placement targets are hard to recognize.** The current striped plate gets a thick mint perimeter, four fixed upright light markers and a real nearby light even before the crate is picked up. It disappears when that plate is satisfied or is no longer the current goal. The smaller green landing box still uses the actual validated Q placement point; this cue is separate from the gold navigation route. No collider, interaction or automatic placement is added by the light.
5. **The interface feels generic.** The opening and ending use warm paper framing, original procedural pumpkin/bat silhouettes, rounded buttons and a bundled Berkshire Swash title face. Instructions and buttons retain readable Noto type; the decorative face is only used for the English game brand. Seven language choices remain; fresh preferences default to English. Existing player language/look preferences are respected.
