# Route visibility and core placement review / v0.11

Date: 2026-10-15. Direct user feedback: the gold route was difficult to see without looking down, and the held core could not be placed on a worktop.

## Findings and changes

The old route was a thin translucent floor line; its screen arrow included vertical displacement. Large walking instructions also covered nearby floor space. The route now uses an opaque 0.38-unit gold line, stationary raised lantern-shaped markers along the same physics-checked path, and a horizontal compass. A walking instruction card narrows when the next walking destination is distant. R restores level pitch while retaining yaw; it does not move the player or automatically turn the camera. Route markers are depth-tested, have no colliders and hide in modal screens.

Q previously used validated floor placement, which intentionally rejects worktops. Inserting the core into a machine used E. E and Q now share the actual socket Use transition when carrying the core near an available visible machine/relay. Broad console-surface/socket reach accepts a level view and nearby peripheral approach while rejecting walls and retaining machine prerequisites. Away from a socket Q retains floor placement; crate placement safety remains intact. The large insertion coach only replaces the current socket objective, so passing a finished machine does not replace archive directions.

The supplied screenshot also visibly showed desktopHold pause, where gameplay input is disabled. This establishes that screenshot's state, not the cause of every earlier failed placement attempt. Desktop pause now presents a dedicated explanation that E/Q are inactive until Enter/Resume, hiding active gameplay instructions. OS access and explicit look-entry controls remain available.
